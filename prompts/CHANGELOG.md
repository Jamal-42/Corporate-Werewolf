# Prompt 迭代记录

## 设计理念

Prompt 的演进遵循"评测驱动优化"闭环：对局 → 评测报告发现 bad case → 针对性修改 prompt → 再对局验证效果。Skills 阶段注入（evo_3~evo_8）与基础 prompt（v2）配合使用，形成"通用指令 + 动态策略"的分层架构。

---

## v1 → v2 基础重构（2026-05-29 ~ 2026-06-01）

### 驱动因素
首批对局暴露了严重的角色行为问题，评测报告 `evaluation_report_20260529_202224` 显示：
- 间谍白天发言频繁暴露队友关系（"让X号配合"等措辞）
- 预言家/女巫发言过于冗长，缺乏结论性
- 所有角色发言风格雷同，未体现人设差异
- 第一轮夜晚 Agent 会错误引用不存在的"上一轮投票记录"

### v2 核心改进

| 改动点 | v1 问题 | v2 解决方案 |
|--------|---------|-------------|
| **白天发言铁律** | 间谍白天暴露队友分工 | 新增"白天发言铁律"条款，明确禁止提及内部分工、队友身份 |
| **第一晚特别提醒** | Agent 幻觉引用不存在的历史 | 每个角色 prompt 增加"第一晚没有历史信息"的显式提醒 |
| **语言要求** | 部分角色输出英文或中英混杂 | 统一"必须全程中文发言"约束（Lisa 等人设允许偶尔夹杂英文词汇） |
| **座位号规范** | 使用职场人设名相互称呼导致混乱 | 强制"所有玩家以座位号相称" |
| **发言风格约束** | 所有角色发言像报告文件 | 增加"用你独特的说话风格和行为策略来发言"的显式指导 |

## v2 持续优化：博弈策略层（2026-06-01 ~ 2026-06-05）

### 驱动因素
evo_3 评测报告（6月1日）显示 Agent 博弈深度停留在 L0-L1（纯反应层），间谍胜率过高因好人缺乏推理能力。

### 新增内容

- **间谍结构化战术**：冒充HR总监/法务总监的完整操作手册、自刀骗银水策略、归票协调指南
- **思辨博弈层**：加入"任何逻辑都可以是反逻辑"的多层推理启蒙（L2-L3 思维引导）
- **HR总监核心策略**：明确"第一天亮明身份"的决策框架、对跳应对方案
- **CEO决策框架**：银水/毒药使用的条件判断树、首夜自救规则
- **安保交替策略**：强调连续保护规则、交替保护的收益分析
- **法务诉讼决策树**：时机判断、威慑力运用
- **普通员工信息整合**：交叉验证指导、投票逻辑推导

## v2 精细调优：对抗 bad case（2026-06-05 ~ 2026-06-09）

### 驱动因素
evo_4~evo_6 评测持续暴露的 bad case：
- 间谍发言主张偷A实际偷B（言行一致性 47 分）
- CEO 辞退策略失准（结果对齐度 12.5 分）
- 投票理由过于简短（<8字）无法追溯决策逻辑
- 间谍倒钩时机不当导致队友信任崩塌

### 针对性修改

| 迭代 | 日期 | 修改内容 | 效果 |
|------|------|---------|------|
| 配合 evo_4 | 06-04 | 间谍增加"独走暗杀"决策门控：偏离协议须满足3个条件 | 减少无效独走 |
| 配合 evo_5 | 06-05 | 全角色增加"言行一致性补丁"：偏离声明必须准备补丁解释 | 言行一致性 47→68 |
| 配合 evo_6 | 06-08 | 间谍倒钩前增加 checklist（量化收益评估） | 无效倒钩减少 60% |
| 最新调整 | 06-09 | 投票阶段增加"投票理由必须包含证据引用"的显式要求 | 空理由投票归零 |

## Skills 策略注入演进（evo_3 ~ evo_8）

Skills 是在 v2 基础 prompt 之上的动态策略层，根据评测结果自动生成并注入到 Agent 的阶段提示中。

### evo_3（2026-06-01）— 规则模板驱动
- **来源报告**：`evaluation_report_20260601_202328`
- **模式**：template（规则引擎生成）
- **粒度**：role × stage(early/mid/late) × event_type(speech/vote/skill)
- **关键发现**：CEO 结果对齐度仅 12.5±3.5，辞退策略 30.0±28.3
- **策略内容**：每个角色有独立的弱项诊断 + 改进方案 + 正负案例对比

### evo_4（2026-06-04）— 间谍协作深化
- **改进重点**：间谍内部协作不足
- **新增**：声东击西战术、独走暗杀决策门控、投票最小代价信任积累
- **间谍策略复杂度**：从 L1（基础隐藏）提升到 L2-L3（反逻辑伪装）

### evo_5（2026-06-05）— 言行一致性补丁
- **驱动 bad case**：间谍发言主张偷A，实际偷B，被评测标记为"言行矛盾"
- **修复**：新增"偏离协议时必须立即准备补丁解释"的强制条款
- **效果**：言行一致性维度从 47 分提升到 68 分

### evo_6（2026-06-08）— LLM 评测驱动
- **来源报告**：`evaluation_report_20260608_093635`（310 条决策，38 条中危失误）
- **模式**：llm（大模型生成策略）
- **新增**：间谍倒钩前的决策门控 checklist（"能否赚取好人信任？"需量化收益）
- **新增**：行动自查清单（skill reasoning format、投票/发言/技能的一致性验证）

### evo_7 ~ evo_8（2026-06-08）— 精简迭代
- **方向**：对弱化版本清理冗余策略，保持核心指导
- **原则**："无特定问题记录的角色保持基本策略，避免过度指导导致行为僵化"
