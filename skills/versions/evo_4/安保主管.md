## 安保主管决策指导 Skills

### 致命缺陷优先处理

#### 保护技能使用（保护策略 / 信息利用）
- **保护策略得分 0.0**：当前所有保护行动均未产生有效收益，常见错误为 **“信息遗漏/违反规则”**。  
- **强制规则**：禁止连续两晚保护同一目标；每晚必须选择一名存活的非自身角色。  
- **首夜必保 HR 总监**（最可能被杀的核心神职），之后在 **HR 总监 → CEO → 法务总监** 之间强制轮换，宁可保护次优目标也不得因犹豫而漏保或违规。  
- 每次天亮后立刻记录自己昨晚的保护对象及其存活状态，作为后续推理的硬信息。

#### 投票与共识对齐（结果对齐度 / 言行一致性）
- **结果对齐度 0.0，言行一致性 50.0**：当前策略仅为“跟从归票”，缺乏关键轮次的主动归票，导致行动与好人胜利逻辑脱节。  
- 在中期放逐投票前，**必须利用保护信息** 提出归票建议：若你保护过某玩家且当晚出现平安夜，可暗示该玩家偏好人，引导票型离开他。  
- 后期一旦亮明身份，直接以安保主管的权威归票：根据存活神职状况，指出“我今夜保护 X，若我倒牌则 X 大概率是狼”，迫使狼队刀法受限。

### 博弈与推理深度提升

#### 推理质量（得分 10.0）与信息利用（得分 15.0）
- **诊断**：缺失从狼人视角反推行踪的能力，未曾使用保护信息缩小狼坑。  
- **具体动作**：  
  - 每早公布死讯后，立即反推：若死者是好人，狼队为何刀他而不是你保护的玩家？你保护的玩家中是否有故意被绕开的狼？  
  - 把每晚保护对象标记为 **“暂时安全”**，但警惕 **“自刀狼”** 可能混入被保护名单，后期需通过发言矛盾检验。  
  - 当你的保护导致平安夜时，优先分析被保护者是否可能为 **“狼队造平安夜做身份”**，对比其投票和发言是否前后一致。

#### 博弈深度（得分 5.0）
- **诊断**：纯被动跟随，未利用安保主管的身份威慑进行心理博弈。  
- **中期行动**：在未亮身份时，可通过发言故意抛出“我疑心某玩家，但我不能明说原因”，制造信息差，让狼队误判你可能是预言家或安保主管，从而改变刀法。  
- **亮身份时机**：若你已保护过 CEO 且该夜平安，应立刻跳明身份，迫使狼队必须处理你，为预言家争取轮次。跳身份后立刻提供详细保护日志，增加可信度。

### 分阶段可执行指令

#### 前期 (early)
- **发言**：只做中立分析，不暴露保护倾向。可用“感觉某玩家挂相”替代真实保护信息。  
- **投票**：紧跟预言家出票，避免分票。若预言家未出现，投票给发言最像躲推且不在你保护名单中的玩家。  
- **技能**：绝对保护 **HR 总监**。若 HR 总监首夜已死，改为保护 CEO。

#### 中期 (mid)
- **发言**：开始为亮身份铺路，暗示“如果我是关键神职，我会如何行动”。若你保护的玩家被踩，可用“我判断他可能不是狼”轻保，不透露缘由。  
- **投票**：利用保护信息辅助推理，仔细对比被保护者的票型——若其票型与受保好人身份矛盾，当晚可考虑换保其他神职，必要时次日点出其疑点。  
- **技能**：按 **HR 总监 → CEO → 法务总监** 顺序轮换，绝不重复保护同一人，除非已到决赛圈且只剩一个明确好人。

#### 后期 (late)
- **发言**：直接跳明身份，完整报出每晚保护目标、结果及推理。例如：“第二夜保 CEO，平安夜，因此 CEO 非自刀狼；第三夜保法务总监，他却死了，说明狼队在绕开我的保护。”  
- **投票**：在决赛圈绝对主导归票，归票对象必须是生存玩家中保护记录最可疑或从未进入保护名单的。  
- **技能**：保护唯一存活神职。若双神均在，优先保护能证明身份的那一个（如预言家未死则保预言家）。

### 关键失误规避
- **信息遗漏/违反规则**：每晚必须提前准备好保护目标，计时结束前必须提交，不得因犹豫导致系统随机保护或漏保。  
- **死板跟从归票**：杜绝纯粹盲从。哪怕跟票，也要在发言中说出“我跟票的理由是我觉得 X 的查验/逻辑比我准”，避免言行割裂。

### 维度弱项专项突破
- **保护策略 (0.0)**：当前全部保护未产生有效收益，可能源于目标选择失误或违反禁止连保规则。必须执行上述首夜保 HR 总监、后续强制轮换的核心纪律。  
- **结果对齐度 (0.0)**：投票与保护动作未服务于好人胜利，必须将保护信息转化为归票依据，并在关键轮次亲自归票。  
- **博弈深度 (5.0)**：缺失身份威慑与反推刀法逻辑，必须练习“假暗示”、“平安夜反推”等技巧，从狼人战术收益出发决定自身行动。  
- **推理质量 (10.0)**：未用保护信息构建狼坑，要求每轮死讯后强制推演狼人刀口逻辑，并记录推理链。  
- **信息利用 (15.0)**：保护信息处于闲置状态，必须在发言和投票中引用“我记下的安全名单”，即使不跳身份也据此调整行为。  
- **言行一致性 (50.0)**：虽未严重矛盾，但跟票策略导致投票与内心保护信息分离，需在发言中补充内心判断，使票型与真实想法同步。  
- **信息隐藏 (50.0)**：目前以隐藏为主，但应当学会在适当时机选择性释放信息，而非永远不露身份，否则保护价值无法兑现。

### 行动清单
1. **刻入保护规则**：首夜 HR 总监 → 后续 CEO/法务总监轮换，严禁连保。  
2. **建立保护日志**：每夜记录 → 天亮分析死讯与保护关系 → 发言中逐步使用。  
3. **定位归票嫌疑**：末期把未进保护名单或保护后发言矛盾者作为第一归票目标。  
4. **练习博弈话术**：在中期发言中植入“若我是关键神职”的模糊信息，衡量狼队反应。
